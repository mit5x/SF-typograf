Кнопка «Оттипографить» в правой колонке редактора: исправляет типографику
в контенте страницы и в текстовых полях ACF с предпросмотром изменений.

== Description ==

Плагин добавляет в правую колонку экрана редактирования записи или страницы
кнопку «Оттипографить». По клику открывается окно предпросмотра, где для
каждого поля показано текущее значение и то, во что его превратит типограф.
Изменения вносятся только в отмеченные чекбоксами поля; выбор запоминается
для каждой страницы отдельно.

Правила основаны на «§ 62. Экранная типографика» (Артемий Лебедев):

* спецсимволы и знаки в тексте: (C) → ©, (R) → ®, (TM) → ™, ... → …, +- → ±, 2x3 → 2×3, No 5 → № 5;
* кавычки: «ёлочки» снаружи и „лапки“ внутри (или английские “…” / ‘…’);
* тире: дефис между словами заменяется длинным тире, числовые диапазоны — коротким;
* перенос слов и привязки: неразрывные пробелы после предлогов и союзов,
  у инициалов, чисел с единицами измерения, знаков № и §, частиц «бы», «же», «ли»;
* неразрывные диапазоны &lt;nobr&gt; для телефонов и слов через дефис (по желанию).

Обрабатываются только поля ACF типов «Текст» и «Область текста». Тип поля
проверяется на сервере по ключу поля, поэтому ссылки, изображения, файлы,
отношения и другие нетекстовые поля плагин не трогает. Дополнительно
пропускаются значения, которые выглядят как ссылка, путь, имя файла,
e-mail, число, JSON или одиночный шорткод.

HTML-разметка не ломается: теги, атрибуты, HTML-комментарии (в том числе
разметка блоков Gutenberg), шорткоды, сущности и содержимое &lt;pre&gt;,
&lt;code&gt;, &lt;script&gt;, &lt;style&gt; остаются нетронутыми.

Движка два: встроенный (работает локально, без внешних запросов) и
веб-сервис «Типограф» Студии Артемия Лебедева. При недоступности сервиса
плагин автоматически переключается на встроенный.

== Installation ==

1. Скопируйте папку `sf-typograf` в `/wp-content/plugins/`.
2. Активируйте плагин в разделе «Плагины».
3. При необходимости настройте правила: «Настройки → SF Typograf».

== Frequently Asked Questions ==

= Изменения сохраняются сразу? =

Нет. Плагин подставляет исправленные значения в поля редактора, а страницу
вы сохраняете сами обычной кнопкой «Обновить». Это позволяет отменить
правку, просто не сохраняя страницу.

= Как исключить поле из обработки навсегда? =

Снимите чекбокс напротив поля в окне предпросмотра и нажмите «Применить».
Выбор сохранится для этой страницы и будет применён при следующих запусках.

= Поддерживается ли Gutenberg? =

Да. Кнопка выводится в панели «Документ», контент разбирается и собирается
обратно средствами блочного редактора.
