# SF Typograf

Плагин WordPress: кнопка **«Оттипографить»** в правой колонке редактора записи или
страницы. Исправляет типографику в контенте редактора и в текстовых полях ACF —
с предпросмотром изменений и выбором полей.

* Каталог плагина: [`sf-typograf/`](sf-typograf/)
* Исходные материалы: [`sourses/`](sourses/) — «§ 62. Экранная типографика» и
  PHP-клиент веб-сервиса «Типограф» Студии Артемия Лебедева.

## Что делает

Правила взяты из «§ 62. Экранная типографика»:

| Раздел § 62 | Что делает плагин |
| --- | --- |
| Спецсимволы | `(C)` → `©`, `(R)` → `®`, `(TM)` → `™`, `...` → `…`, `+-` → `±`, `2x3` → `2×3`, `No 5` → `№ 5`, `§`, `°` |
| Кавычки | `"текст"` → `«текст»`, вложенные → `„текст“` (или английские `“…”` / `‘…’`) |
| Тире | `слово - слово` → `слово&nbsp;— слово`, `1990-2000` → `1990–2000`, `--` → `—`, тире в начале строки |
| Перенос слов | одно- и двухбуквенные слова, короткие предлоги и союзы привязываются к следующему слову |
| Привязки | инициалы `В. И. Пупкин`, `№ 5`, `5 кг`, `1 000 000`, `20 %`, `т. е.`, частицы `бы`, `же`, `ли`; опционально `<nobr>` для телефонов и слов через дефис |
| Знаки в тексте | подстановка настоящих знаков вместо их эмуляции |

## Как это работает

1. В правой колонке редактора появляется метабокс «Типографика» с кнопкой
   «Оттипографить».
2. По клику плагин собирает текущие (в том числе несохранённые) значения:
   контент редактора (классический и блочный), при желании заголовок и все
   поля ACF типов «Текст» и «Область текста», включая подполя повторителей
   и гибкого контента.
3. Значения уходят на сервер, где тип каждого поля ACF **перепроверяется по
   ключу поля** через `acf_get_field()`. Поля других типов — ссылки,
   изображения, файлы, отношения — не обрабатываются.
   Ключи полей поддерживаются любые: и автогенерированные (`field_5f3a…`),
   и заданные вручную в PHP или JSON (`field_my_field_name`).
4. Открывается окно предпросмотра: крайняя левая колонка с чекбоксами
   (по умолчанию отмечены), затем название поля, текущее значение и результат
   типографа с подсветкой различий.
5. По кнопке «Применить» изменения вносятся только в отмеченные поля, а
   состояния чекбоксов сохраняются в мете записи `_sf_typograf_field_states` —
   отдельно для каждой страницы. У подполей повторителей и гибкого контента
   номер строки в ключе не учитывается: исключается поле целиком, поэтому
   добавление или перестановка строк не сдвигает сохранённый выбор.
6. Изменённые поля подсвечиваются, страница прокручивается к первому из них.
   Ничего не сохраняется: значения только подставлены в форму, страницу
   администратор сохраняет сам обычной кнопкой «Обновить».

## Безопасность данных полей

Помимо фильтрации по типу поля, значение пропускается, если оно выглядит как
ссылка или путь, имя файла, e-mail, число или телефон, JSON, сериализованные
данные или одиночный шорткод. Внутри текста не затрагиваются HTML-теги и
атрибуты, HTML-комментарии (включая разметку блоков Gutenberg), шорткоды,
сущности, ссылки и содержимое `<pre>`, `<code>`, `<script>`, `<style>`.

Обработка идемпотентна: повторный запуск на уже обработанном тексте ничего
не меняет.

## Вывод спецсимволов

Настройка «Вывод спецсимволов» определяет, чем типограф пишет знаки в поле:

| Режим | Результат для «Сайт для вашего бизнеса - за 5 рабочих дней» |
| --- | --- |
| `entities` (по умолчанию) | `Сайт для&nbsp;вашего бизнеса&nbsp;&mdash; за&nbsp;5&nbsp;рабочих дней` |
| `mixed` | `Сайт для&nbsp;вашего бизнеса&nbsp;— за&nbsp;5&nbsp;рабочих дней` |
| `chars` | `Сайт для вашего бизнеса — за 5 рабочих дней` (неразрывные пробелы — невидимые символы U+00A0) |

Сущности удобны тем, что правку видно прямо в поле. Символы UTF-8 короче, но
неразрывный пробел неотличим от обычного. Если шаблон выводит поле через
`esc_html()`, сущности покажутся на сайте как текст — тогда нужен режим `chars`.

Сущности разбираются обратно в символы перед каждой обработкой, поэтому режим
можно менять в любой момент, а повторный запуск типографа ничего не портит.

## Журнал обмена с веб-сервисом

Поля обрабатываются по очереди, поэтому окно не остаётся пустым: видна полоса
прогресса, номер текущего поля и журнал, который дополняется на лету одной
строкой на поле:

```
Контент редактора | Ответ взят из кэша — запрос к веб-сервису не отправлялся.
Заголовок · HTTP 200 · 112 ms · ↑ 578 B · ↓ 500 B | Успешно: HTTP 200, 112 мс.
Текст под заголовком · HTTP 200 · 163 ms · ↑ 771 B · ↓ 692 B | Успешно: HTTP 200, 163 мс.
```

С веб-сервисом поля идут по одному, чтобы был виден каждый обмен; встроенный
типограф обрабатывает их пачками по пять. «Отмена» останавливает очередь.

Если выбран движок «Веб-сервис «Типограф» Студии Артемия Лебедева», после
обработки окно показывает полный журнал обмена: адрес, HTTP-код, время ответа,
размеры запроса и ответа и их содержимое. Ошибки соединения и SOAP-ошибки выводятся
отдельно, а блок журнала раскрывается сразу. В подвале окна написано, чем
выполнена работа — веб-сервисом или встроенным типографом, — и поля,
обработанные сервисом, помечены. Если сервис недоступен, поле дорабатывает
встроенный типограф, и причина отката видна в журнале.

## Настройки

«Настройки → SF Typograf»: движок (встроенный или веб-сервис «Типограф»),
стиль кавычек, вывод спецсимволов, включение отдельных правил, типы записей
с кнопкой, обработка заголовка.

## Программный интерфейс

```php
// Обработать произвольный текст текущими правилами.
echo sf_typograf()->typograf( $text, 'html' ); // или 'text'

// Расширить список типов полей ACF.
add_filter( 'sf_typograf_allowed_acf_types', function ( $types ) {
    $types[] = 'wysiwyg';
    return $types;
} );
```

Доступные хуки: `sf_typograf_allowed_acf_types`, `sf_typograf_post_types`,
`sf_typograf_settings`, `sf_typograf_field_context`, `sf_typograf_processed_value`,
`sf_typograf_trust_client_field_type`.

Последний нужен, только если поле не удаётся найти через `acf_get_field()` —
тогда плагин примет тип поля, определённый в браузере, но по-прежнему пропустит
значения, похожие на ссылку, файл, число или JSON:

```php
add_filter( 'sf_typograf_trust_client_field_type', '__return_true' );
```

## Правила типографики как документ

[`.claude/skills/typograf/SKILL.md`](.claude/skills/typograf/SKILL.md) — те же правила
в виде инструкции для Claude Code: что менять, что не трогать никогда, три режима
вывода, справочник знаков и чек-лист проверки. Работает тремя способами:

* `/typograf путь/к/файлу.php` — вызов вручную;
* автоматически, если попросить «оттипографь текст в этом файле»;
* `@.claude/skills/typograf/SKILL.md` — подключить как справочник к своей задаче.

Чтобы правила действовали во всех проектах, а не только в этом репозитории:

```sh
cp -r .claude/skills/typograf ~/.claude/skills/
```

Документ и движок плагина описывают один и тот же набор правил — меняя одно,
надо менять и другое.

## Требования

WordPress 7.0+, PHP 7.4+. ACF не обязателен — без него обрабатывается
контент редактора.
